Portfólio & Laboratório de Desenvolvimento

Repositório central para experimentação, prototipagem e desenvolvimento de projetos pessoais, incluindo meu portfólio web e o assistente de inteligência artificial Ultron.

Visão Geral do Repositório

Este espaço serve como um ambiente de trabalho ativo onde construo, refino e testo minhas aplicações. Atualmente, o repositório abriga a base do meu Portfólio Profissional e os primeiros módulos e recursos multimídia do assistente de voz Ultron.

Nota de Desenvolvimento: Todos os projetos aqui contidos encontram-se em fase ativa de construção, refatoração de código e melhorias contínuas. Novas funcionalidades são adicionadas regularmente!

1. Portfólio Web

Um espaço digital estruturado do zero para centralizar minha apresentação profissional, destacando experiências, competências técnicas e projetos desenvolvidos.

Foco: Layout limpo, navegação intuitiva e design responsivo.

Tecnologias: HTML5 e CSS3 puro.

Próximos Passos: Refinamento de animações, otimização para dispositivos móveis e integração de novas seções interativas.

2. Projeto Ultron (Assistente de Voz)

O Ultron é um assistente inteligente experimental concebido para automatizar tarefas cotidianas, interagir por comandos de voz e integrar recursos avançados de automação e IA.

Componentes Atuais:

app-debug.apk: Build de testes mobile voltado para experimentação de interfaces no Android.

ultron.jpg: Identidade visual e avatar oficial do assistente.

Ultron musica.mp3: Arquivo de áudio imersivo para interações e ambientação.

Próximos Passos: Expansão das rotinas em Python, integração com APIs de reconhecimento de fala e refinamento do aplicativo mobile.

Tecnologias e Habilidades

Linguagens: Python, JavaScript, HTML5, CSS3, SQL.

Qualidade de Software (QA): Selenium WebDriver, Cypress, Cucumber, Postman.

Ferramentas de Desenvolvimento: Git, GitHub, Android Studio, VS Code.
